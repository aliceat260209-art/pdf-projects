# 跟孙武学英语

《孙子兵法》全十三篇中英文学习版。

## Files

- `output/gensunwu-complete-learning.pdf`: final PDF
- `output/gensunwu-complete-learning.html`: printable HTML source
- `source/complete-sunzi-learning.js`: structured learning content
- `source/build-complete-sunzi-pdf-html.mjs`: PDF HTML generation script copied from the React project

## Notes

This version uses selected public-domain passages from 《孙子兵法》 with original Chinese guidance, English learning text, vocabulary, short stories, and discussion prompts.
