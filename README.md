# Chinese Classics Bilingual Learning

中国经典智慧中英双语学习库

This repository collects bilingual learning materials based on Chinese classics,
including Chinese-English study PDFs, printable HTML exports, vocabulary notes,
reading prompts, and source files for future updates.

本仓库用于持续整理中国经典智慧的中英双语学习素材，适合英语学习、亲子共读、传统文化阅读、课堂补充材料和个人精读。

## Structure

```text
projects/
  project-name/
    README.md
    output/   # final PDF / HTML exports
    source/   # content data, scripts, notes, or source assets
```

## Workflow

1. Create one folder under `projects/` for each PDF project.
2. Put final downloadable files in `output/`.
3. Put editable source files in `source/`.
4. Commit each meaningful version so changes can be tracked.
